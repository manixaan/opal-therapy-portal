# Therapist First-Login Checklist (one page)

Print or keep open beside the Quick-Start Guide. Tick as you go.

**Before you start** (owner confirms these are done for you):
- [ ] Registration link received (email or sent directly by the owner)
- [ ] Practice Microsoft (Outlook) account details known

**Day one — in order:**
- [ ] 1. Open your registration link → set a strong password → register
- [ ] 2. If the screen says "pending approval", tell the owner — they
      approve you in seconds
- [ ] 3. Log in
- [ ] 4. Complete every onboarding step, including the final review step
- [ ] 5. Open **My Profile** → check the **Account setup status** card —
      it lists your exact next steps
- [ ] 6. Confirm your **home/travel base** (Profile → Work location)
- [ ] 7. **Settings → Integrations → Connect Outlook** — sign in with your
      PRACTICE Microsoft account
- [ ] 8. Wait ~2 minutes → calendar shows your Outlook appointments; the
      header pill shows your own mailbox + a real sync time
- [ ] 9. Check the setup card again — Splose link row should say *Linked*
      (if "pending — practice owner", nudge the owner)
- [ ] 10. Open **Resource Hub** → *Induction / new therapist resources* →
      read the first-week checklist there
- [ ] 11. Try a test **leave request** (My Profile → Leave → save as
      draft, then delete it) so you know where it lives
- [ ] 12. Log out and back in once — everything should still be there

**If anything fails**: note the step number + screenshot → owner. Nothing
you do can write to Outlook, Splose or Xero during the pilot.
