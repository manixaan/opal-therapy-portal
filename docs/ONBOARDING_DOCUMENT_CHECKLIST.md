# Onboarding documents — what to supply

Pulled from the deployed staging library on 21 August 2026. **36 documents.**

Two kinds of work, and they must not be mixed up:

- **DOWNLOAD** — a statutory or regulator document. Opal republishes it *verbatim*.
  The system marks these `owner_controlled = false` so nobody can edit the text.
  Get the current PDF from the source and upload it as a new version.
- **CREATE** — Opal's own policy. Nobody else can write it, and the portal
  deliberately seeds it as an empty slot rather than inventing something
  authoritative-looking.

> **Current state warning.** The 31 documents marked *placeholder* below hold a
> single line of text — `"Synthetic staging content."` — published during earlier
> staging tests. There is no real content in the library anywhere. A generated
> starter pack is currently 27 files totalling 7 KB.
