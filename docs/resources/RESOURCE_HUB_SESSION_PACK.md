# Resource Hub — Therapist Feedback Session Pack

Practical materials for the first content/feedback session. Companion to
`RESOURCE_HUB_FEEDBACK_PLAN.md` (the why) and
`RESOURCE_HUB_CONTENT_SEEDING_PLAN.md` (the folder pack). Everything here is
synthetic/template material — **no client information anywhere**, and no real
clinical documents are uploaded unless Antony supplies them.

---

## 1. Session agenda (60 minutes)

| Time | Item |
|---|---|
| 0–5 | Show the Resources tab live on staging: search, tags, a sample resource card, favourite, download. One message: *"this is yours to shape."* |
| 5–15 | Walk the 12 proposed folders (seeding plan). Ask: what's missing, what's mislabelled, what would you never open? |
| 15–35 | The 11 feedback questions (checklist below) — capture answers per therapist on the form (§7) |
| 35–45 | "Recreated worksheets" harvest: each therapist names their top 2 documents they keep rebuilding — these become the first upload batch |
| 45–55 | Product links: build the first 10 together using the template (§5) — including the Kmart/Big W alternates they actually recommend |
| 55–60 | Agree next step: who submits what as drafts this fortnight; remind them drafts go through review before appearing |

## 2. Therapist question checklist (tick as asked)

☐ Which folders would you use weekly? ☐ Which diagnoses first? ☐ Which
therapy areas first? ☐ What do you constantly recreate? ☐ What products do
you recommend most (incl. cheap alternates)? ☐ What session ideas would help
a new grad? ☐ What parent handouts are missing? ☐ What do schools keep
asking for? ☐ What PD/research should live here? ☐ How should client
suggestions look *eventually* — and where would they annoy you? ☐ **What
should never be suggested automatically?** (record verbatim — becomes hard
exclusion rules)

## 4. File naming convention

`[Area]_[Topic]_[Audience]_v[N].pdf` — e.g.
`FineMotor_CuttingSkillsProgression_Therapist_v1.pdf`,
`Sensory_HeavyWorkMenu_Parent_v1.pdf`.
Rules: no client names ever · no dates in names (version instead) · audience
∈ Therapist/Parent/School/Admin · ASCII only, no spaces (underscores).

## 5. Product-link template (one per product)

```
Product name:            e.g. Therapy putty (medium resistance)
Supplier + URL:          
Category:                fine motor | sensory | oral | seating | AT | game
Approx price + currency: AUD — mark "checked on <date>"
Low-cost alternative:    e.g. Kmart kinetic sand — URL
Age suitability:         
Clinical use case:       one sentence, no client details
Safety notes (REQUIRED): choking / supervision / inspection & replacement
Tags:                    from the seeded vocabulary
```

## 6. Resource-quality checklist (before status = approved)

☐ Title/description clear, audience obvious ☐ Correct folder + ≥2 tags
☐ Source cited; copyright OK (link, don't re-host, if unsure) ☐ Safety
notes present where relevant (mandatory: oral/chewing, products, anything
weighted/suspended) ☐ Age suitability stated ☐ **No client information of
any kind** ☐ Naming convention followed ☐ Reviewer + review-due date set
(auto 12 months) ☐ For products: price/link checked, alternative listed
