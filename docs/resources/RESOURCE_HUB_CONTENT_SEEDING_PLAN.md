# Resource Hub — Content Seeding Plan (first content pack)

Companion to `RESOURCE_HUB_FEEDBACK_PLAN.md`. Uses the R1 foundation only —
no client-linked suggestions, no AI, no external sharing. Owner/admin create
the folders below in the portal (Resources tab), then upload/link starter
content; therapists review and give feedback before wider rollout.

**Upload instructions (owner/admin):** Resources tab → create resource
(title, description, type, tags, safety notes, source/copyright) → upload
PDF/DOC (validated, private, authenticated downloads only) or add an
external/product URL → status `approved` makes it visible to therapists;
therapist submissions arrive as drafts for your review.

Owner-only material (analytics, governance queue) stays in the existing admin
views — no owner-only *content* folder needed initially.

## Feedback loop
Seed 2–3 items per folder → run the 11 questions in
`RESOURCE_HUB_FEEDBACK_PLAN.md` with therapists → reshape folders/tags from
answers → only then bulk-populate. Question 11's answers ("never suggest
automatically") are recorded now and become hard exclusion rules before any
Phase R5 suggestion work.
